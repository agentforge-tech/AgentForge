BUILDING BLOCKS

为 Agent 工程而生

六个核心能力覆盖模型接入、工具调用、执行治理与工作台落地。

01MODEL

Unified LLM

OpenAI、Anthropic 与 OpenAI-compatible 服务共享一套 ChatModel 契约，上层代码不被厂商协议锁定。

02RUNTIME

Agent Runtime

ReActAgent 围绕 think → act → 记忆写回组织执行，同步与流式共用同一套循环、取消和步长控制。

03ACTION

Tool Calling

本地 Java 方法、HTTP 插件与 MCP 服务统一转换为 Function Call，参数绑定、执行与结果回写一次完成。

04GOVERNANCE

Middleware

在模型调用、工具执行与 Loop 生命周期挂载日志、Trace、审计和脱敏逻辑，横切能力与主循环解耦。

05STREAM

Messages & Events

统一消息模型与流式事件，让同步结果、推理增量、工具调用和前端 SSE 收敛到同一套语义。

06SERVICE

Service Workbench

模型配置、Agent 调试、版本发布、会话重放与链路追踪开箱即用，直接体验完整 Agent 工作台。

ARCHITECTURE

自底向上的 Agent 技术栈

从协议契约逐层向上组合，任何一层都可以独立替换。

QUICK START

几十行代码，跑通第一个 Agent

注入模型、记忆与工具，选择同步或流式执行。同一个 ReActAgent 实例可以在两种模式间自由切换。

开始构建→阅读 Agent 设计↗
FirstAgent.javaJAVA
ReActAgent agent = ReActAgent.builder()
        .chatModel(chatModel)
        .streamingChatModel(streamingChatModel)
        .chatMemoryProvider(new MessageWindowChatMemoryProvider(50))
        .toolService(toolService)
        .middleware(new LoggingIAgentMiddleware())
        .build();

ChatResult result = agent.run(AgentRequest.builder()
        .memoryId("user-1")
        .question("北京今天天气怎么样？")
        .build());
